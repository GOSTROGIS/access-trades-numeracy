# Textbook chapter exams

The Numeracy Hub exam builder includes a separate switch for each of the textbook’s 13 numbered chapters and an optional Appendix A switch. **Textbook only** selects the 13 chapters and switches off other banks; instructors can then narrow the chapter selection. Each generated exam uses the existing answer checker, worked solutions, calculator keys, exam-code rebuild, PDF and Word exports.

The chapter bank follows `source/book/chapters/` and adds 77 randomized question types. Its chapter references are chapter names, so a textbook pagination change does not break the references.

| 5 · Decimals | Rounding, lengths, prices, decimal feet, division to thousandths | 5 |

`numeracy-hub/exam-textbook.js` supplies the framework and chapters 1–8/Appendix A. `exam-textbook-geometry.js` supplies chapters 9–13. Geometric figures are generated by the Hub’s existing Shape Canvas engine from each question’s actual givens. The factories also run under CommonJS for testing.

The new registry entry is appended after every existing bank. Visual presentation puts the chapter switches first without changing registry indices, preserving previously issued exam codes. Do not reorder registered banks, existing chapter modules, or task lists when preserving a published exam code matters. New modules belong at the end.

Rounding uses 14 significant digits before formatting to remove binary arithmetic tails at exact decimal halfway points while retaining substantially more precision than displayed answers. Whole-sheet counts use an integer ratio to avoid an extra sheet at an exact boundary. No intermediate result is deliberately rounded for calculations. Given waste factors and simplified geometry assumptions are stated in each question; exercises do not silently assume building-code limits.

Run the dependency-free checks from the repository root:

```sh
node source/exam/test-textbook.cjs
```

The suite uses the real Hub exam core and TI-30Xa/Shape Canvas engines. It checks 9,240 generated cases across all five difficulty settings; reproducible prompts and codes; displayed, exact and unit-suffixed answer acceptance; wrong-answer rejection; geometry validity; calculator sequences; 25-question generation for every chapter; independent arithmetic from prompts; half-cent monetary rounding; and a whole-sheet boundary regression. Browser checks should also cover chapter-only selection, individual switches, fresh/rebuilt exams, downloads, existing bank compatibility, and mobile layout.
