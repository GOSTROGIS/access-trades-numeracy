# ACCESS Trades Numeracy

Math practice, books and calculators for ACCESS Trades pre-apprentices in fabrication, pipe trades and millwright.

## Get the latest version

1. Click the green **Code** button at the top of this page, then **Download ZIP**.
2. Unzip the folder.
3. Open `index.html` in a web browser (double-click it).

Everything runs in the browser. Once the folder is downloaded, the hub, the canvas and the calculators work with no internet connection. When there is an update, download the ZIP again and replace your old folder.

## What is in the folder

| Open this | What it is |
|---|---|
| `index.html` | The home page, with links to everything below |
| `numeracy-hub/index.html` | Numeracy Hub: shapes, order of operations, volume and layout, angles and trig, fabrication, pipe trades, unit conversions, mechanical aptitude, coordinate systems, measuring tools and the exam builder |
| `shape-canvas/index.html` | Shape Canvas: drag shapes onto a sheet, change their sizes, unfold them into nets and mark up the work |
| `calculators/` | TI-30Xa, Sharp EL-531XT and HP-15C calculators that work in the browser |
| `books/` | Textbook, Exercise Book and Answer Key (PDF, US Letter) |

Your progress in the hub is saved in the browser you use. Using a different browser or computer starts a fresh record.

## Carpentry Foundation — Intake 141

Open [the daily math deck index](carpentry/intake-141/START-HERE.html) after downloading the repository. The package covers all 26 scheduled math days and 50 lesson blocks from October 29 to December 16, 2026.

- [Editable PowerPoints](carpentry/intake-141/PowerPoint/): full daily lessons with speaker notes, textbook references, exercises, and Numeracy Hub/Shape Canvas activities.
- [Daily PDFs](carpentry/intake-141/PDF/): viewing and printing copies without speaker notes.
- [Instructor guide](carpentry/intake-141/Instructor/Instructor-Guide.pdf) and [schedule index](carpentry/intake-141/Daily-Deck-Index.xlsx): teaching plans, answers, and schedule mapping.

Keep the complete `carpentry/intake-141/` folder together so its links to the included offline ACCESS books and tools continue to work. See [the package instructions](carpentry/intake-141/READ-ME.txt) for details.
