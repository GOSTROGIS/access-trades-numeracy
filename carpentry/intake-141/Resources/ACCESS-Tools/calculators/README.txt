ACCESS Trades calculators
=========================

Four web pages, each one a single file. Open any of them in a web browser (double-click it). They need no
internet connection and no other files: the calculator, the fonts and the ACCESS logo are all inside each file.
Keep the four together in a folder so the links between them work.

ti30xa.html
    A working TI-30Xa calculator, full size. Click its keys or type on the keyboard.
    Beside it: "How this calculator works" (how keys are entered, mixed numbers, angle units, rectangular and
    polar coordinates, memories, keyboard keys) and "Watch the keys", worked examples that the calculator
    presses for you one key at a time.

el531xt.html
    The same for the Sharp EL-531XT. Its notes cite the pages of the Sharp manuals they come from.

hp15c.html
    The same for the HP-15C, the RPN calculator (number, ENTER, number, then the operation). Its notes cite the
    pages of the HP-15C Owner's Handbook they come from.

calculators.html
    All three calculators on one page. Pick one with the switcher at the top (or the menu on the calculator).
    The notes and the worked examples change with it. The choice is remembered in this browser and is shared
    with the Numeracy Hub's calculator choice. The three single-calculator pages never change that choice.

The calculators are the same ones the ACCESS Trades Numeracy Hub uses, so they give the same answers as
the hub.
